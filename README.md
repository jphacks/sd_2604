## 製品概要
### 背景
待ち合わせと遅刻は表裏一体

「ごめんちょっと遅れる！」とか「やっぱ１時間後にしない？」とか日常茶飯事なわけです。~~特に学生~~

しかし、どれだけ責めてももう時間に間に合わないんだからどうしようもない。
それなら待ってる側も好きに時間を過ごせるようにしてあげれば遅刻の罪悪感も和らぐしwin-winだよね！

待ち合わせ×tech、遅刻する側とされる側ちょうど半々なチームによる両者に優しいプロダクトです。
### 製品説明
## 機能
- ルーム作成
- 集合場所・時間の設定
- メンバーの位置情報
- 上記の情報を地図に表示
- 集合場所からの直線距離表示
- 到着予想時刻の算出、表示
- 予想時刻に対してユーザー側から任意で変更をかける
- プライバシー保護のためのジャミング
