# もうつく

## 製品概要
### 背景
待ち合わせと遅刻は表裏一体

「ごめんちょっと遅れる！」とか「やっぱ１時間後にしない？」とか日常茶飯事なわけです。~~特に学生~~

しかし、どれだけ責めてももう時間に間に合わないんだからどうしようもない。
それなら待ってる側も好きに時間を過ごせるようにしてあげれば遅刻の罪悪感も和らぐしwin-winだよね！

待ち合わせ×tech、遅刻する側とされる側ちょうど半々なチームによる両者に優しいプロダクトです。
### 製品説明
ワンクリックで待ち合わせをアシスト！
気まずい時間を気楽に、有意義に！

「もうつく」は、遅刻の連絡に伴う「気まずさ」と、待たされる側の「いつ来るかわからないストレス」を同時に解消するロケーション共有Webアプリです。

URLを共有してルームに入るだけで、メンバーの現在地と「本当の到着予定時刻」がマップ上にリアルタイム表示されます。遅れる側は、焦って歩きスマホで言い訳のメッセージを打つ必要はありません。画面を開くだけで状況が伝わるため、安全に急ぐことができます。

一方、待つ側は相手の正確な到着時間がわかるため、「いつ来るかわからないからその場を動けない」という状況から解放されます。待ち時間を「近くのカフェで休む」「本屋に寄る」といった自分のための有意義な時間に変えることができます。

連絡の手間と罪悪感を削ぎ落とし、お互いの時間を尊重し合える。ストレスフリーな新しい待ち合わせ体験を提供します。
## 機能
- ルーム作成
- 集合場所・時間の設定
- メンバーの位置情報
- 上記の情報を地図に表示
- 集合場所からの直線距離表示
- 到着予想時刻の算出、表示
- 予想時刻に対してユーザー側から任意で変更をかける
- プライバシー保護のためのジャミング
## 特徴
### 簡単な操作
遅刻する人間は大抵急いでいます。
時間を報告するテキストを打っている暇なんてありません。
もうつくではURLを踏んでルームに参加するだけで現在地、到着予定時間の共有が可能です。
### テキストでのやりとりなし
従来の待ち合わせではLINEやDiscordを使いテキストで連絡を行います。
すると「遅刻する！」となった場合、まずメンバーに謝る必要が出てきます。
しかしそれこそが手間。待っている側は謝るよりいつ来るかを知りたいわけですし、謝るという1テンポが報告のハードルを上げてしまっているのです。
もうつくはテキストでのやり取りなし！
地図と時間が表示されるだけのUIにより報告のハードルを下げています。
### 位置情報のジャミング
いくら待ち合わせのためとは言え、自分の家の場所までは知られたくないですよね？
もうつくでは集合地点から500m以上離れた段階で具体的な位置が秘匿され、さらにオプションのジャミングをかければサーバーに送られるのは集合地点から距離のみとなり、プライバシーを守りながら遅刻できます！
